# 第一轮研究：选题约束修订

日期：2026-11-03
状态：RESEARCH_ONLY

## 一、固定条件

- 多语言覆盖范围为既定的 66 门语言。
- 不再将选择哪些语言作为主要选题问题。
- go-dev v2 继续保持最高优先级。
- 最终商业目标是长期自然流量和广告净收益。

## 二、内容来源选择

优先考虑：

- 具有长期学习或查询价值的资料；
- 原始内容质量较高；
- 允许翻译、修改及商业再分发；
- 官方尚未建立成熟的多语言内容体系；
- 内容更新及维护成本可控。

若上游已经支持广泛的多语言版本，
原则上暂缓重复翻译项目。

必须评估未来官方自行扩展翻译的替代风险。

## 三、原创内容原则

不强制要求所有内容均为深度原创。

优先调查以下模式：

1. 获授权的高质量翻译；
2. 翻译与可控的事实核查、来源整理；
3. 复用开放数据的轻量级增值工具。

独立原创研究可以作为未来方向，
但必须单独评估时间成本。

翻译授权不等于广告平台批准。

## 四、候选项目修订

### Rust

在固定 66 门语言中调查内容覆盖、
翻译质量、竞争与上游替代风险。

### AI 基础学习

优先调查没有成熟多语言体系、
且具备明确商业授权的基础教材。

吴恩达课程具有研究价值，
但课程商业翻译授权仍为 UNCLEAR。

### DeepSeek

海外使用需求有公开数据支持。

仍需验证 API 文档本地化搜索需求，
以及具体内容的商业翻译许可。

### Shopify

暂缓整站文档复制翻译。

继续调查 Liquid、Theme Liquid Docs
等具有明确开源许可证的资料。

### 历史、地理与公共知识

允许将合法授权翻译作为基础模式。

调查低成本事实核查、背景资料整理
及轻量交互工具是否具有商业价值。

不默认必须撰写原创深度评论。

## 五、下一轮研究要求

优先核实具体内容来源，
而不是笼统讨论行业热度。

每个候选记录：

- 具体来源与许可证；
- 授权核实日期；
- 现有多语言覆盖情况；
- 上游自行扩展多语言的风险；
- 搜索需求及竞争证据；
- 预期维护工作量；
- 广告政策适配性。

没有可靠数据时标记 UNKNOWN。
授权存在歧义时标记 UNCLEAR。

不启动正式翻译或网站开发。
