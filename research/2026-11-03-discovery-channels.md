# 多语言项目内容发现渠道清单

核实日期：2026-11-03
状态：RESEARCH_ONLY
阶段：CHANNEL_DISCOVERY_CONFIRMED

## 一、研究目标

建立稳定、可复用的内容源发现渠道。

本阶段仅确认渠道，不筛选具体项目。

最终商业目标：

通过多语言内容网站或交互式工具网站，
获取长期自然搜索流量和可持续广告净收益。

语言覆盖范围为既定的 66 门语言。

go-dev v2 仍然是当前主项目。

## 二、主渠道

### 1. GitHub

https://github.com/search?type=repositories

主要领域：

- 编程语言
- AI 基础知识与应用开发
- 开源技术文档
- 开源学习教材

发现能力：

- 仓库搜索
- Topic 分类
- License 筛选
- 更新情况及项目维护状态调查

注意：

GitHub 仓库许可证不一定覆盖所有文档、
图片、数据及第三方素材。

### 2. Open Textbook Library

https://open.umn.edu/opentextbooks

主要领域：

- 计算机科学
- 数学与自然科学
- 地理与历史
- 人文与社会科学

主要价值：

发现结构相对完整、适合长期学习的开放教材。

注意：

必须确认具体教材是否允许商业翻译。
带有 NC 或 ND 限制的内容不能直接纳入商业翻译项目。

### 3. Pressbooks Directory

https://directory.pressbooks.pub/

主要领域：

- 开放教材
- 多学科教学资源
- 互动学习内容

主要价值：

可结合学科、许可证等条件发现教材。

注意：

目录收录不代表所有教材均允许商业翻译。

### 4. OER Commons

https://www.oercommons.org/

主要领域：

- AI 与计算机科学
- 数学和科学
- 世界历史与地理
- 政治制度与社会科学

主要价值：

通过学科、语言和使用条件等维度筛选资源。

注意：

必须进一步确认原始作品的实际授权。

## 四、专项开放数据来源

## 五、辅助研究工具

允许使用：

- Google
- Bing
- ChatGPT 联网搜索
- 官方项目网站
- 原始许可证文件
- 官方数据与统计机构

主要用途：

1. 验证项目来源及许可证。
2. 调查已有多语言版本。
3. 搜索竞争网站及搜索结果。
4. 验证自然搜索需求。
5. 补充发现渠道遗漏。

不以无约束的互联网搜索作为
主要候选项目发现方式。

## 六、内容源发现原则

1. 优先使用已确认的发现渠道。
2. 不为达到候选数量而强行寻找项目。
3. 优先寻找完整、长期有效的内容资产。
4. 优先考虑允许商业翻译及独立再分发的资料。
5. 必须区分代码、文档、图片和数据许可证。
6. 不能依据仓库开源推断整个网站可商业转载。
7. 官方已有成熟多语言体系的项目降低优先级。
8. 必须调查上游后续增加翻译的替代风险。
9. 固定 66 门语言范围，不因单一项目随意变更。
10. GitHub Star、内容数量不代表自然搜索流量。
11. 商业许可不等于 AdSense 自动批准。
12. 新渠道必须说明新增理由及潜在价值。

## 七、阶段划分

### CHANNEL_DISCOVERY_CONFIRMED

当前阶段。

确认内容源发现渠道及其用途。

不筛选具体项目。

### SOURCE_DISCOVERY

下一阶段。

从已经确认的渠道中发现具体内容源。

记录：

- 项目名称
- 官方地址
- 内容类型
- 许可证线索
- 已有语言版本
- 维护情况

### SOURCE_SCREENING

核实具体内容源的：

- 商业翻译授权
- 上游多语言替代风险
- 内容寿命
- 维护成本

### MARKET_RESEARCH

核实：

- 长期自然搜索需求
- 国家及语言市场
- 搜索竞争
- 广告变现可能性
- 潜在净收益与机会成本

不得跳过授权核查，
直接启动正式内容翻译。
