# 多语言项目选择边界与候选开放原则

日期：2026-11-03
状态：RESEARCH_ONLY
决策状态：NOT_DECIDED

## 一、当前已确定事项

go-dev v2 是当前主项目。

继续优先完成现有项目的开发与上线。

新的多语言项目不得影响 go-dev v2。

既定目标语言范围为 66 门。

长期商业目标：

通过有价值的多语言内容网站或工具网站，
获得可持续的全球自然搜索流量和广告净收益。

## 二、编程语言项目数量

前期暂按总共两门编程语言考虑，
其中 Go 已确定。

但两门只是当前初步设想，
并非正式数量上限或强制建设目标。

未来可能只保留 Go，
也可能增加其他编程语言项目。

数量必须由商业机会与维护能力决定。

## 三、第二门编程语言尚未确定

不得预设 Python 或 Rust 必然入选。

允许调查包括但不限于：

- Python
- Rust
- Ethereum 智能合约开发语言，如 Solidity、Vyper
- 其他具有长期商业价值的编程语言

Ethereum 相关内容的具体授权、
广告政策及合规风险需要另行核实。

候选列表开放，不因已有研究顺序而锁定。

任何编程语言均须经过相同的商业评估。

## 四、第二个多语言项目独立决策

第二个正式多语言项目，
不一定是第二门编程语言。

它可以来自：

- AI 基础知识及应用开发
- 应用安全，如 OWASP
- 编程语言与开发技术
- 世界地理
- 世界历史、人文与文明
- 开放数据及交互式工具
- 政治制度与公共知识
- 其他经过研究的新领域

以上只是候选范围，不是项目路线图。

不得预设技术领域优于非技术领域。

不得预设 AI 是最佳方向。

## 五、选择顺序与研究顺序不同

SOURCE_DISCOVERY：
发现值得调查的内容源。

SOURCE_SCREENING：
核实许可证、内容及有效语言覆盖。

MARKET_RESEARCH：
调查搜索需求、竞争、用户价值与维护成本。

PROJECT_DECISION：
综合比较后决定是否正式立项。

优先研究某个候选，
不等于承诺优先建设该项目。

此前对 Rust、Python、OWASP
以及历史教材的研究均为证据积累。

不存在已经批准的下一项目。

## 六、工期及机会成本

完整编程语言多语言项目，
初步估计可能需要约六个月。

该估计尚未通过实际工作量验证。

不能将六个月直接套用于：

- 历史教材项目
- AI 教程项目
- OWASP 应用安全资料
- 数据查询与交互工具
- 其他非编程语言候选

每个方向必须独立估算建设和维护成本。

## 七、正式决策标准

重点评估：

1. 长期自然搜索需求。
2. 目标语言市场及用户价值。
3. 原始内容商业授权。
4. 已有翻译的实际覆盖和质量。
5. 上游未来替代风险。
6. 搜索竞争及差异化价值。
7. 初期建设时间与资金成本。
8. 长期更新及质量审核成本。
9. Google AdSense 等合法变现条件。
10. 长期广告净收益与机会成本。

不得将以下指标视为成功目标：

- 翻译页面数量
- 支持语言数量
- GitHub Star 数量
- 单一技术领域的流行程度

缺乏证据的商业指标标记 UNKNOWN。
