# Multilingual Project Research

**多语言项目研究与启动前规划（Multilingual Project Research & Pre-Launch Planning）**

本仓库用于研究具有长期自然搜索需求、明确商业使用许可、真实用户价值与可持续广告收益潜力的多语言内容网站或交互式工具网站。

- **当前状态**：`RESEARCH_ONLY`
- **当前主项目**：go-dev v2（最高优先级）
- **已选第二项目**：`WORLD_HISTORY`（世界历史，选型完成、启动前规划中，未批准正式开发）
- **完整范围与阶段边界**：[PROJECT_SCOPE.md](PROJECT_SCOPE.md)

## 项目范围

1. **候选研究**：发现技术与非技术领域的项目，核实需求、竞争、授权、目标市场与长期商业价值。
2. **正式选型**：确定是否选择、暂停、继续研究或放弃候选项目，保留证据与不确定性。
3. **已选项目启动前规划**：核查官方内容源、版权、语言与地区变体、章节质量、网页阅读体验及轻量工程可行性；形成未来独立实施项目的交接记录。

这三个阶段都属于研究。**项目被选中不代表获准翻译、开发或部署。**

正式翻译、大规模内容生产、生产网站工程、域名/DNS和部署等工作不属于本仓库职责，必须由负责人另行授权，原则上进入正式项目的独立仓库。

## 当前已选项目：世界历史（WORLD_HISTORY）

目前选定三部官方开放教材：HIS-A、HIS-B、HIS-C。三本书均已取得官方出版来源的 PDF；HIS-C 另取得官方 XML。更细的源版本、语种、许可与体验研究保留在 `research/` 中。

已明确：
- 正式翻译输入必须来自出版机构的官方原文，不直接采用第三方/社区镜像。
- 规划的 66 门目标语言包含七种英语地区变体；原始语言与目标地区语言的覆盖需要分别判断。
- 若官方只有 PDF、没有合格的完整 HTML，可以研究制作具有实际阅读价值的网页版；不为了形式统一自动重复制做全部已有官方网页。
- **世界历史正式开发至少等 go-dev v2 完成以后；也可能等到 go-dev v3，具体时间未知。** go-dev v2 完成也**不会自动触发**世界历史开发，仍需单独授权。
- 当前仅开展不影响 go-dev v2 的低成本研究与启动前规划，**不会启动世界历史正式翻译或建站**。

## 持续研究的领域

候选领域不限于技术教程，包括：Rust/Python等编程技术、AI及DeepSeek等模型文档、商业开发平台、世界地理、世界历史与人文知识、政治制度、开放数据及交互式比较工具。新方向仍需独立进行市场、竞争与商业授权调查，不预设某一领域必然优于其他领域。

## 评估和记录原则

- 商业目标是**长期自然流量、用户价值与广告净收益**，不是翻译页数、支持语言数或 GitHub Star 数。
- 优先研究未来 3～5 年仍有价值的内容，并核算后续维护成本。
- 对许可证、搜索表现、市场规模、收入和法律条款尽可能提供原始来源与核实日期。
- 区分 `VERIFIED`、`ESTIMATE`、`UNKNOWN`、`UNCLEAR`；不编造广告 RPM、自然流量或商业回报。
- 正文、源码、图片、模型权重、外部数据和服务条款须分别审核，不能以正文的 CC 许可直接覆盖第三方媒体。
- 研究保持低成本、可恢复、可中断；不建设第二套完整翻译工程，不修改 go-dev 主项目。
- 研究成果记录在 Git；提交信息中文优先，使用 Conventional Commits 格式。

已完成的世界历史选型与初期规划报告**继续保留在本仓库**，无需迁移或删除。未来真正批准实施时，再整理一份交接索引供独立项目仓库引用。
